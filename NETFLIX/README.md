# 🎬 Netflix Clone - Frontend Web Project

A modern, responsive clone of the **Netflix India** homepage built using vanilla **HTML5**, **CSS3 (Flexbox & CSS Grid)**, and **JavaScript**.

## ✨ Features

- **Iconic Netflix Hero Section:** Custom dark gradient overlay, high-resolution backdrop, and dynamic SVG brand logo.
- **TV & Video Showcase:** Seamless video playback nested inside responsive TV and device bezels using CSS positioning.
- **Interactive FAQ Accordion:** Smooth JavaScript-powered accordion for expanding and collapsing frequently asked questions.
- **Client-Side Form Validation:** Email format verification with user feedback prompts.
- **100% Fully Responsive:** Adapts cleanly across mobile phones, tablets, and widescreen desktop monitors using modern CSS Flexbox and media queries.
- **Clean Semantic Code:** HTML5 markup with accessibility-friendly tags (`<header>`, `<main>`, `<section>`, `<footer>`, `<form>`).

---

## 🛠️ Built With

- **HTML5:** Semantic markup, video embeds, and accessible form structures.
- **CSS3:** Flexbox, CSS Grid, custom gradients, animations, and responsive breakpoints.
- **JavaScript (ES6):** DOM manipulation, accordion logic, and form validation.

## 💻 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ANKITT2006/NETFLIX_WEB-Frontend-Dev-.git
   ```
2. **Navigate into the folder:**
   ```bash
   cd NETFLIX_WEB-Frontend-Dev-
   ```
3. **Open `index.html`** in your browser:
   - Double-click `index.html`, OR
   - Right-click and choose **"Open with Live Server"** in VS Code.
